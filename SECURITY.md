# Política de Segurança

O Canetada roda 100% no navegador, sem servidor e sem coleta de dados: o progresso fica apenas no `localStorage` de quem joga.

Mesmo assim, se você encontrar uma vulnerabilidade (por exemplo, em dependências ou no processo de build/deploy), **não abra uma issue pública**. Use o recurso [Report a vulnerability](https://github.com/MoreiraGustav/canetada/security/advisories/new) do GitHub ou contate a pessoa mantenedora pelo perfil [@MoreiraGustav](https://github.com/MoreiraGustav).

Responderemos o quanto antes e daremos crédito a quem relatar, se desejar.
